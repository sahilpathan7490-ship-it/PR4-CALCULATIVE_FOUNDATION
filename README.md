# 📊 CALCULATIVE FOUNDATION

### Linear Algebra & Mathematical Analysis Using Student Performance Data

## 📌 About the Project

This project applies **Linear Algebra and Mathematical Foundations** to a student performance dataset containing **200 student records**.

The project demonstrates how mathematical concepts can be used for practical data analysis using **Python, NumPy and Pandas**.

## 📂 Dataset

The dataset contains student scores in four subjects:

* `STUDENT_ID`
* `MATH`
* `SCIENCE`
* `ENGLISH`
* `HISTORY`

Each student is represented as a **4-dimensional vector**:

```text
[Math, Science, English, History]
```

## 🎯 Concepts Covered

* Vector Representation
* L1 & L2 Norm
* Dot Product
* Angle Between Vectors
* Cross Product
* Vector Projection
* Matrix Addition
* Matrix Multiplication
* Matrix Transpose
* Determinant
* Matrix Inverse
* Dimensionality & Hyperplanes
* Covariance Matrix
* Eigenvalues
* Eigenvectors

## 📊 Key Outcome

The project shows how student performance data can be represented using **vectors and matrices**, and how covariance, eigenvalues and eigenvectors can be used to understand the structure and variation of the data.

## ✅ Conclusion

This project connects **theoretical Linear Algebra with practical data analysis**, making concepts such as vectors, matrices, covariance and eigenvectors easier to understand through real student-performance data.
